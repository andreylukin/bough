bough UI design brief

A coding agent you daily-drive. Five surfaces of one macOS window — converse, gate the network, review changes, and navigate a branching history with many heads. Amber circles are annotations, keyed to the notes beside each screen.

ANNOTATIONS
1

Two tabs share the rail — Network and Changes — with unread/pending counts. The rail collapses to a hairline to hand the width back to the conversation.

2

The current head reads top-to-bottom as an outline; the live turn pulses green. ⤢ Map pushes open the across-heads graph (screen 02).

3

Worker sub-agents and tool calls fold into quiet inline groups — collapsed by default, one click to expand. A running worker carries the amber pulse.

4

One-key branching lives in the composer. Editing any earlier turn and re-sending forks a new head rather than overwriting.

5

A hold-and-ask request is the one thing allowed to shout: amber card, the danger verb in muted red, resolved inline. See screen 03.

6

Every outbound request streams into the feed, classified as host · action. Green allowed, red denied — glanceable proof nothing slipped out.

ANNOTATIONS
1

Every head is a lane. The active head's spine is green; forks (edit-&-resend, worker attempts) branch off the turn they diverged from. A dead worker attempt keeps its red tip so you can see what was tried.

2

One zoom axis runs from whole tree → a single head → a single turn. The same graph reads at every altitude — no separate views to learn.

3

Drag across a span to select it (amber band), then Compact → branch collapses those turns into a summary node on a fresh head. A compaction dashed node (⊟ 18→1) marks where it already happened. Click any node to jump there, or fork from it.

ANNOTATIONS
1

Bundles are browsed like packages — publisher, version, a verified signature, install count. Installing one loads its policy into the gate.

2

Each bundle declares typed parameters — text, select, multi-select, toggle, number — and bough renders the matching control. The user configures a safe form; there's no raw policy file to fat-finger. The green toggle keeps destructive verbs on hold-and-ask.
