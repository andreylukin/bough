## Switching the tools consumer (Andrey's go, taken 2026-08-28)

The tree ships TWO consumers of the `tools` seam and boots CODE MODE. All three code-mode rows
(`js`, `js.quickjs`, `tools.codemode`) are ENABLED in `bundles/bough-base.yml`, and
`profiles/tui.yml` / `profiles/headless.yml` compose `bough-codemode` last — so `bough` (bare) and
`bough exec` run code mode with no flags.

```sh
bough --patch bundles/bough-typed.yml    # the fallback: the typed tool set, over any profile
#   entries:
#     tools.codemode: { disabled: true }
```

Nothing is removed either way: `tools`, `tools.baseline`, `tools.operator` and every other typed
row stay mounted and executable under code mode too. What changes is what the MODEL is shown — one
`run(program)` tool instead of the typed set.

The full prose, including how to make the fallback permanent, is `docs/configuration.md`.
