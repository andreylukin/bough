# Bundled hooks

Shipped with bough and materialized to `~/.bough/bundled-hooks/<version>/`.
Every one of them is **off until you turn it on** in the hooks panel (`^x`) —
an upgrade must never start running code you did not ask for.

To own one, copy it into `~/.bough/hooks/`: files there are yours, load last,
and are on by default.
